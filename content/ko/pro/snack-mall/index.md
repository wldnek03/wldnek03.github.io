[🖥️ Server Repository](https://github.com/wldnek03/snack_server) ・ [🌐 Client Repository](https://github.com/wldnek03/snack_client)

국가별 식료품 구매 수요를 반영한 웹 기반 쇼핑몰 **"달콤 스낵 노마드"** 프로젝트를 진행하며 **백엔드 개발**을 담당했습니다. 사용자 편의성을 고려한 상품 조회 및 데이터 처리 기능을 구현하였으며, 국가별 상품 정보를 효율적으로 관리할 수 있는 구조를 설계했습니다. 또한 이미지 분류 기반 기능을 적용해보며 머신러닝 기술을 서비스에 활용하는 경험을 했고, 팀원과 협업하며 서비스 흐름과 사용자 경험을 개선하기 위한 기능을 지속적으로 논의했습니다.

**주요 작업**

- 상품 조회 · 검색 · 데이터 처리 API 설계 및 구현
- 국가별 상품 정보를 효율적으로 관리할 수 있는 데이터베이스 구조 설계
- 이미지 분류(머신러닝) 기반 기능 적용
- 클라이언트-서버 간 데이터 흐름 정의 및 협업

**사용 기술**

- Backend: Node.js / Express
- Database: MySQL
- ML: 이미지 분류 모델
- 협업: Git / GitHub
