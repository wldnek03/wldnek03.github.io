종자 증식실의 환경 데이터를 실시간으로 수집·모니터링하고, 실제 증식실을 **3D 디지털 트윈**으로 시각화하여 환경 시뮬레이션·수확량 예측까지 지원하는 시스템 개발 프로젝트에서 **백엔드 개발과 서버 관리**를 담당하고 있습니다. 센서 데이터를 안정적으로 처리하고 사용자에게 실시간 정보를 제공할 수 있는 구조를 구현하고 있으며, 데이터 흐름과 사용자 활용성을 고려하여 시스템을 개선하고 있습니다. 프로젝트를 진행하며 서비스 운영 관점의 문제 해결 경험과 협업 기반의 커뮤니케이션 역량을 키우고 있습니다.

**주요 작업**

- 증식실을 3D로 시각화한 **디지털 트윈** 화면 구현 (로트 · 센서 · 중계기 인터랙션)
- 온도 · 습도 · 일사량 · CO₂ 등 환경 시뮬레이션을 통한 **권장 환경 추천 · 수확량 예측** 기능
- 센서 데이터를 안정적으로 처리하는 백엔드 구조 설계 및 구현
- 사용자에게 실시간 환경 정보를 제공하는 데이터 파이프라인 구축
- 로트 관리 · 센서 그래프 · 알림 이력 · 리포트 등 운영 기능 제공
- 서버 운영 · 배포 · 모니터링 환경 구성
- 데이터 흐름과 사용자 활용성을 고려한 시스템 개선

**사용 기술**

- Frontend: 3D 디지털 트윈 시각화 (Three.js / WebGL)
- Backend: Node.js / Express
- IoT: 센서 데이터 수집 및 처리
- Server: Linux 서버 운영
- 협업: Git / GitHub
